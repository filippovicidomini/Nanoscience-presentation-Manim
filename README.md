
# A Visual Journey Through Semiconductors, PN Junctions, and LEDs

This project is an educational and visual exploration of semiconductor physics, designed to bridge the gap between microscopic physical mechanisms and macroscopic electronic behavior.
The final output is a short explanatory video that guides the viewer from the atomic structure of silicon to the functioning of a PN junction and light-emitting diodes (LEDs).

The entire visualization pipeline combines scientific accuracy, custom animations, and video editing, making it suitable for academic presentations, outreach, and teaching purposes.

## Project Overview
This project presents a short educational video that visually explains the fundamental physics of semiconductors, from the silicon crystal lattice to PN junction operation and light emission in LEDs, linking microscopic mechanisms to macroscopic device behavior.


## Software and Tools Used
Custom scientific animations were created using Manim, while DaVinci Resolve was used for video editing, timing optimization, audio synchronization, and final rendering of the complete video.
